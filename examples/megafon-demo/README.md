# Демонстрационный проект: бриф МегаФона

«Бриф на разработку стратегии продукта / продуктового направления - Связь для близких и
собственных устройств». Официальный бриф демонстрационного проекта номинации «ИИ-проект».
Оператор вымышленный, все числа учебные.

| Файл | Что |
|---|---|
| `demo-brief-megafon.pdf` | бриф как получен (11 страниц) |
| `demo-brief-megafon.txt` | текстовый слой PDF (`pdftotext -layout`), если нет `pypdf` |

## Как запустить
1. Откройте папку агента в IDE (Claude Code, Cursor, Codex) и начните новый чат.
2. Первое сообщение, например: «Вот бриф руководителя: examples/megafon-demo/demo-brief-megafon.pdf.
   Нужна стратегия по нему. Проект назови megafon-demo».
3. Агент сам загрузит бриф (`import`), разберёт его на фрагменты и пойдёт по этапам. Человек
   отвечает на вопросы постановки, разрешает новые сайты и выбирает вариант.

Без `pypdf` PDF загрузится как заблокированный (`dependency_missing`); тогда дайте агенту `.txt`.

## Что получится
`projects/megafon-demo/exports/document.md` - документ из пяти частей брифа с расчётами рядом с
решениями и коммуникационной стратегией; `report.md` - приложение с полной доказательной базой.
