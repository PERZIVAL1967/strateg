# Стратег Фабрики продуктов

ИИ-агент для руководителя цифрового продукта: ведёт от размытого запроса до обоснованной продуктовой
и коммуникационной стратегии и не бросает после решения. Каждое сведение - с источником и точной
цитатой, факты отделены от гипотез и прогнозов, решения принимает человек, работа продолжается после
перерыва.

Работа команды PERZIVAL1967 и Basil с ИИ-агентами Claude Code и Codex для номинации «ИИ-проект»
MGIMO AI Challenge 2026.

- **Видео демонстрации (9:53):** ссылка в форме отправки работы (Google Диск)
- **Описание работы (PDF):** [docs/strateg-description.pdf](docs/strateg-description.pdf)
- **Демонстрационный проект МегаФона:** [demo/megafon-demo/](demo/megafon-demo/)

## Как это устроено
Агент - это папка, а не программа. Её открывают в среде с ИИ-моделью (Claude Code, Cursor, Codex),
и модель становится «Стратегом».

| Что | Где |
|---|---|
| Постоянные правила агента | [AGENTS.md](AGENTS.md) (`CLAUDE.md` подключает его автоматически) |
| Навыки по этапам | [skills/](skills/) - постановка, сбор, исследование, варианты, стратегия, документ, пересмотр, продолжение, интервью, данные |
| Методика | [method/](method/) |
| Инструмент состояния | [tools/strat.py](tools/strat.py) - единственный, кто пишет состояние проекта (SQLite + файлы источников по sha256) |
| Проекты | `projects/<id>/` - создаются при работе, в Git не хранятся |

## Запуск
**Нужно:** Python 3.9 или новее; среда с ИИ-моделью и доступом к терминалу - Claude Code (подписка
Claude), Cursor или Codex. Платные API, ключи и серверы не нужны.

1. Скачайте репозиторий.
2. Для чтения PDF (необязательно): `pip install -r requirements-optional.txt`.
3. Проверка: `python tools/strat.py init --project test` и `python tools/strat.py doctor --project test`.
4. Откройте папку в Claude Code (или Cursor, Codex) и начните новый чат, например:
   > Вот бриф руководителя: examples/megafon-demo/demo-brief-megafon.pdf. Нужна стратегия по нему. Проект назови megafon-demo

Дальше агент сам заводит проект, загружает бриф и идёт по этапам. Человек отвечает на вопросы
постановки, разрешает сайты-источники и выбирает вариант. Итог - `projects/<id>/exports/document.md`
(документ для руководителя) и `report.md` (полная доказательная база).

**Перерыв:** закройте чат, откройте новый в той же папке и напишите «Продолжай» - агент восстановит
этап из базы.

**Новые данные:** дайте агенту файл с уточнением - он загрузит его как новый источник, покажет через
`impact`, какие выводы от него зависят, и пересчитает их.

**Перенос на другой компьютер:** `python tools/strat.py archive --project <id> --out p.zip`, затем
`python tools/strat.py restore --project <id> --file p.zip`.

**Тесты:** `python -m pytest -q tests` - 165 тестов (macOS - 8 минут, Windows - 21,5 минуты).

## Демонстрационный проект
[demo/megafon-demo/](demo/megafon-demo/) - результат записанного прогона по брифу МегаФона:
- `megafon-demo-strategy.pdf` - стратегия в PDF;
- `exports/document.md` - итоговый документ (пять частей брифа, расчёты рядом с решениями,
  продуктовая и коммуникационная стратегии, план проверки);
- `exports/report.md`, `exports/claims.md` - доказательная база: источники, цитаты, утверждения;
- `exports/context.md` - где проект сейчас и что дальше;
- `finance-update.txt` - новые данные, по которым агент пересмотрел расчёты;
- `megafon-demo-archive.zip` - архив проекта: восстановите его командой `restore` и продолжайте работу.

Исходный бриф - [examples/megafon-demo/](examples/megafon-demo/). Использованы только открытые данные.
В архиве и выгрузках путь к домашней папке автора заменён на `/Users/demo/`.

## Ключевые решения
1. **Папка вместо программы.** Агент работает в любой IDE с моделью и не требует сервера.
2. **Один писатель состояния.** Модель не правит базу напрямую: только команды `strat.py`, каждая
   отвечает JSON (`status`, `error_code`, `retryable`). Поэтому состояние проверяемо и переживает
   сбои и перерывы.
3. **Цепочка доказательств.** Источник → неизменяемая версия → фрагменты → точная цитата → утверждение
   с типом → варианты, стратегии, решения. Связи хранятся в базе, поэтому видно, что затронут новые данные.
4. **Человек решает.** Список сайтов, выбор варианта и решение - только словами человека.
5. **Ничего не удаляется.** Устаревшее заменяется с причиной и остаётся в истории.
6. **Безопасность.** Команды из источников не меняют правила; загрузка только с разрешённых сайтов,
   частные адреса запрещены; секретов в репозитории нет.
