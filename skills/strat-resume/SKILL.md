# Продолжение после перерыва

1. `python tools/strat.py context --project <id>` - прочитай `stage`, `open.operations`, `next.next_step`.
2. Возьми аренду: `python tools/strat.py lease --project <id> --session <имя-чата>`. Если `LEASE_HELD`,
   спроси человека, закрыт ли прошлый чат; только после «да» - `--takeover`.
3. Для каждой операции из `open.operations` повтори **ту же команду с теми же `--run` и `--step`**
   (адрес или файл - в `input_uri`). Инструмент сам решит: доделать по сохранённой квитанции без
   повторной загрузки, начать новую попытку или ответить `skipped`. Не меняй номер шага.
4. Снова `context`. Этап должен смениться. Дальше - навык из `next.skill`.
5. Человеку скажи одной-двумя фразами: где остановились, что доделано, что дальше.

Готово, когда `open.operations` пуст.
